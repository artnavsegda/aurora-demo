Aurora demo backend

Это эмулятор прод-протокола horizont для Aurora и Halo. Фронтенд не найден: задайте AURORA_DIST=/путь/к/dist (и, при необходимости, HALO_DIST=/путь/к/halo/dist).

Проверка API:

  • POST /script/auth — любой непустой username;
  • POST /script/wrapper?schemas — список схем;
  • POST /script/dashboard — сводка;
  • GET /healthz — здоровье.
